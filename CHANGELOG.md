## [0.4.0] — 2026-11-09

### Исправлено

- **Волны из датапака не загружались:** `WaveLibrary` искал файлы по неверному пути.
  Теперь читается `data/<namespace>/waves.json` из каждого namespace.
- **Конфиг обнулял новые поля:** загрузка переведена на слияние JSON с дефолтами
  (раньше отсутствующий ключ давал `0`/`false`). Файл переехал в `config/lasttrial.json`,
  старое имя читается один раз для миграции.
- **Арены не знали измерения:** одинаковые координаты в разных мирах считались одной
  ареной. Добавлено поле `dim`, данные всегда хранятся в Обычном мире.
- **ПКМ по Реликвии обходил проверки:** старт теперь требует целого пола, свободного
  слота и прав владельца арены (оператор — можно).
- **Подсказка арены** больше не пересчитывает ~100 000 блоков каждый кадр — кэш 500 мс.
- **Ложная пауза на сервере:** лаг-спайк дольше 5 секунд больше не сбрасывает волну;
  определение паузы работает только в одиночной игре.
- **Награда без присутствия:** награду получают только игроки у арены (радиус +24),
  а не все в радиусе 96 блоков и не владелец в другом измерении.
- **Магазин проверял тир по «запомненному» значению** — теперь по активному забегу.
- **Утечка карт магазина** при выходе игрока — добавлена очистка.

### Добавлено

- `docs/AUDIT.md` — 30 глобальных проблем проекта с приоритетами.
- `CHANGELOG.md`, `.editorconfig`.
- Юнит-тесты слияния конфига (4 сценария, всего 22 теста).

## [0.3.0] — 2026-11-09

### Изменено

- Mod id `festival` → `lasttrial`, пакет `com.example.festival` →
  `io.github.kalirsa24.lasttrial`, команда `/lasttrial` (алиас `/ltor`).
- Сборка через Gradle toolchain 17, без жёсткого пути к JDK.
- Лицензия MIT.
- Баланс: хард-режим 120 монет и ×2 монеты; Реликвии в инвентаре — 3 шт. и потолок −60%.
- Забег закрывается через `arenaUnloadStopSeconds` (300 с) на выгруженной арене.

### Добавлено

- Юнит-тесты экономики и тиров, GitHub Actions.
- `docs/ARCHITECTURE.md`, `docs/REVIEW.md`, баннер в `docs/media`.
